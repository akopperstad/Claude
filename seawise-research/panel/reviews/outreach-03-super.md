# Outreach review 03: the former technical superintendent's view

## Verdict on the draft
The draft is decent: short, honest, and it asks for time. But it reads like every startup's discovery message. "Ingen salgspitch" makes a technical manager expect exactly that. "Vedlikehold og drift av fartøy" is so generic that it signals ERP, not engine room. Nothing in it proves you have stood in their shoes, and it asks nothing I would enjoy answering.

## What would make me reply
- **Proof that the sender has done the job.** Say which vessel type and which role. "Maskinist fra Herøy" alone could be anything.
- **A question about my own pain that I can answer in one line.** Then the meeting is just continuing a conversation I've already started.
- **A small ask with an end.** "20 min neste uke" works better than "a day in the next two weeks".
- **Not being sold a "system for everything".** One concrete topic is enough.

## Language that signals "one of us"
- Words to use: *klassebesøk*, *årlig revisjon*, *utestående/forfalte jobber*, *utsettelser*, *Veracity*, *PMS-en*, *kritisk utstyr*, *sertifikatoversikt i Excel*, *chiefen*, *teknisk avdeling*.
- Describe a real task: "jaget utestående jobber og sertifikater i Excel før klassebesøk".
- Avoid: *digitalisering*, *plattform*, *AI*, *operativsystem*, *løsning*, *revolusjonere*.
- **Auditor caution:** never write anything that sounds like backfilling records, such as "kvitterte jobber kvelden før". To a class or ISM person that means falsified records.

## The single hook question
**"Hva måtte dere hente utenfor PMS-en for å bli klare til siste årlige klasse- eller ISM-revisjon?"**

It works for three reasons:
- Every technical manager has a concrete answer: Excel certificate lists, Veracity printouts, e-mail with the chief engineer, deferral lists.
- The answer exposes the real gap between the PMS and compliance, which is exactly Seawise's wedge.
- It doesn't threaten their current PMS choice.

## Recommended message (bokmål, ~425 characters)

> Hei [navn]. Arne Kopperstad, maskinist på havfisketråler, fra Herøy. Jeg har selv jaget utestående jobber og sertifikater i Excel før klassebesøk. Broren min og jeg bygger Seawise og vil lære hvordan teknisk avdeling i [brønnbåt/offshore/nærskipsfart] faktisk jobber. Ett spørsmål: hva måtte dere hente utenfor PMS-en for å bli klare til siste årlige klasse- eller ISM-revisjon? Har du 20 min neste uke? Du får oppsummeringen.

## Notes
- Don't name the current employer (Lerøy Havfisk). "Havfisketråler" is enough, and it avoids a conflict-of-interest question.
- Keep [segment] specific to each recipient. For CEOs, change the question to "hva kostet siste klasse-/dokkingavvik dere i off-hire?"
- Before sending, make sure seawise.no no longer claims that crews are using the product. Technical managers check the website first.
- The same question works as a reply-only follow-up: if they answer only the question, that's a win.
